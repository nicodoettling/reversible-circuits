\section{Problem Formulation}

Let $S_N$ be the symmetric group on $\{1,\ldots,N\}$ and let $T_N$ denote the
conjugacy class of all transpositions.  A length-$m$ transposition word is a
tuple $w=(t_1,\ldots,t_m)\in T_N^m$.  We say that $w$ is an identity word if
\[
  \mathrm{eval}(w) = t_1t_2\cdots t_m = \id.
\]
The canonical fixed-length target is
\[
  \Omega(N,m)
  =
  \{w\in T_N^m : \mathrm{eval}(w)=\id\},
\]
with the uniform distribution on this finite set.

Equivalently, $\Omega(N,m)$ is the set of length-$m$ closed walks at $\id$ in
the Cayley graph $\mathrm{Cay}(S_N,T_N)$.  Thus exact uniform sampling from
$\Omega(N,m)$ is a random-walk bridge problem.  If an exact bridge sampler were
available, the transition at time $j$ would select $t\in T_N$ with probability
proportional to the number of completions from the current product times $t$
back to $\id$ in the remaining number of steps.  This is conceptually clean but
not directly efficient at large $N$.

Throughout the mathematical statements, permutations are maps composed by
\[
  (\alpha\beta)(x)=\alpha(\beta(x)),
\]
so the rightmost displayed factor acts first.  Successive right multiplication
has states
\[
  \id,\quad t_1,\quad t_1t_2,\quad\ldots,\quad t_1\cdots t_m,
\]
and therefore evaluates to the displayed product above.  Historical exact
harnesses that used the opposite tuple-composition convention were translated
before comparison with the statements in this note.
