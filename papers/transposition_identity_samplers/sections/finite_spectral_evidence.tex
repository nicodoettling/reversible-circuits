\section{Finite Spectral Evidence}

heat-bath on the small cases.  The following gaps are finite-state numerical
facts, not asymptotic theorems.

The same run reported that $S_5,m=4$ and $S_5,m=6$ each had one communication
class under $\{3,4\}$ block heat-bath moves, while Hurwitz alone had many
components.  These spot checks are useful evidence for irreducibility, but
they do not constitute a proof.
