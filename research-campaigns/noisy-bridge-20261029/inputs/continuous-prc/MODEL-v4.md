# Frozen source/target model M4

Frozen 2026-10-28 12:25 UTC for GBC-T4. M1/M2/M3 remain preserved. M4 additionally states that both cutoffs are nonnegative rationals; all public evaluation and nonnegative precision conventions remain explicit. This resolves a signed-cutoff finite-prefix ambiguity without changing intended source formats, algorithms or analytic bounds. Standard fixed-word soundness covers bottom/overflow. No-soundness and weaker-null variants remain separate unresolved scopes. No acceptance is implied by this freeze.

## Public finite design

Fix positive rational constants S,N and public uniform polynomial bounds. Every dimension, precision, cutoff and format routine has declared uniform polynomial work/space bounds T_par,S_par, or supplies its evaluated data as explicitly charged input. Complete rational descriptions are charged, including denominators; bounded numerical magnitude is not a bound on representation length. Security index lambda>=1; dimension d(lambda)>=1 is publicly computable and polynomially bounded. All source keys, tapes, work and descriptions have specified polynomial worst-case bounds. Endpoints are uniform randomized finite algorithms; source observers may be nonuniform polynomial-size circuits, matching the project source games. Uniform-observer-only variants require uniform reductions and are to be tracked separately.

The initial supported observation convention is the project's canonical coordinatewise rounding family. A source grid has dyadic mesh Delta_s=2^{-b_s(lambda)}, nonnegative integer polynomial b_s, with Delta_s negligible in lambda, and public nonnegative rational cutoff A_s(lambda) of polynomial numerical magnitude. Round each coordinate to the grid (fixed tie convention), then return one bottom symbol if any rounded coordinate lies outside [-A_s,A_s]. Assume the ideal spherical Gaussian cover overflow is negligible; an explicit sufficient supported schedule has A_s>=lambda times a fixed upper bound on sqrt(S). A receiver uses an independently specified canonical round-then-overflow Q_y with mesh 2^{-b_y}, nonnegative integer polynomial b_y and a nonnegative rational cutoff A_y of polynomial description length. The source and receiver formats may coincide, as in Q_D of the accepted compilers. Represented ordinary words are rational vectors; malformed/bottom inputs are handled by a declared public convention. Any proof relying on a more specific precision/cutoff schedule must state it. No exact real-valued sampler is an endpoint.

The source cover mu_lambda is the probability law of Q_s(G), G~N(0,S I_d). This is a mathematical law on a finite alphabet, not an assumption that irrational atom masses can be sampled exactly with a bounded tape. Effective approximation of its explicit Gaussian cell masses must be proved from finite arithmetic. Public description of Q_s and S is independent of all keys.

For actual project applicability, fix one predetermined legal payload (e.g. all zeros) and accept iff the source decoder returns that payload. This restricts a multi-bit source to zero-bit without reading or extracting internal headers.

## Joint law and quantifiers

SK: K<-Gen(1^lambda), with any allowed public metadata ek exposed once. Enc(K;r) emits a canonical source word; Dec(K,y;t) outputs accept/reject. PK: (pk,sk)<-Gen; Enc(pk;r) uses no secret key; Dec(sk,y;t) accepts/rejects. The same original key law, including setupFAIL and bad keys, is retained throughout. Public metadata/design and pk appear identically in both source worlds.

One source sample draws fresh encoder tape r, AWGN W~N(0,N I_d), and decoder tape t, jointly independent of key and one another. For ordinary C, the physical receiver input is Q_y(rep(C)+W). The bottom convention is fixed in advance; its source probability must be charged rather than conditioned away. Gaussian correctness is key-averaged missed detection <=epsilon_cor(lambda), negligible. Only the exact designated N is assumed. Smaller-noise correctness and norm-perturbation robustness are not assumed.

For every polynomial q and source observer A, the reused-key experiment answering q adaptive source requests with fresh Enc outputs is computationally indistinguishable from fresh independent mu_lambda replies, with the same public metadata or pk. There is no source decoder oracle/feedback. Public encoding can be run by the observer with chosen coins in both PK experiments. A single implementation and precision schedule must serve every polynomial observer, independent of q.

The primary PRC statement assumes standard fixed-word rejection with one common negligible envelope epsilon_FW(lambda): for EVERY fixed symbol y in the ENTIRE finite receiver alphabet, independent of the WHOLE key pair/record, Pr_{Gen,t}[Dec(y;t)=accept]<=epsilon_FW. This includes bottom/overflow; deterministic rejection on exceptional symbols suffices. Malformed inputs deterministically reject. The word may depend on lambda and public fixed design. It may not depend on the sampled pk, hidden key, source transcript, or decoder feedback. A randomized reconstruction preserves this premise only when its law for each fixed binary input is independent of the whole key. Both actual project Gaussian compilers satisfy this standard premise. A source with only source-cover or noisy-cover rejection is not silently upgraded to it.

An oracle-relative variant additionally draws one global oracle O first. All endpoint tapes are independent conditional on O; repeated calls reuse O and the key. Source security and correctness average their declared O/key law. The construction and attack oracle interfaces are a separate theorem, not implicit in M4.

## Binary target

One finite uniform stateless Gen_B/Enc_B/Det_B family, with public polynomial length n_B(lambda), bounded polynomial work/space/tapes and optional preserved PK access. One fixed rational p in (0,1/2) is selected from the public fixed S,N profile before keys/observers. For iid E~Ber(p)^{n_B} jointly independent of the full key and all endpoint tapes, missed detection is negligible over the original target key law. Reused-key, polynomial-many source security compares complete n_B-bit outputs with fresh independent uniform strings, exposing exactly the corresponding public metadata/pk. Preserve whole-key-independent fixed-binary-word rejection with negligible error.

No synchronized state, external shared randomness, out-of-band seed, metadata dependent on an encoded sample, success-conditioned key generation, new hardness assumption, capacity preservation or efficient real-number oracle is permitted. Polynomial block expansion and rate loss are allowed. A theorem at one p does not give a family approaching 1/2.

## Scope still to be investigated

Efficiently approximable real S,N, unknown physical N within public rational brackets, varying S/N, coarse or noncanonical source observation, and the full local-oracle class are not silently included by M4. Their support or obstruction must be resolved explicitly. M4 covers the fixed rational-profile specialization of the accepted SK and PK compiler source conventions; exact applicability still requires reading and checking their algorithms/proofs.
