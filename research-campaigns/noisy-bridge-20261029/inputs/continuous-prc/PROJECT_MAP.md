## The two levels of the problem

The historical public-key application is defined by **ZB-FW-v2** (the new symmetric-key capacity branch has a separate proposed contract in D018): one key, public stateless encoding, joint `(pk, outputs)` covertness, post-pk/post-codeword adaptive bounded-radius corruption, key-averaged correctness and rejection of fresh independent Gaussian cover. No decoder oracle is given. This soundness target differs from standard fixed-word PRC soundness and does not provide authentication. Payload and asynchronous recognition remain explicit later extensions.

**NHR-Haar-rounded-v2** instead reveals a rational public basis B and m jointly quantized samples `z_i=O y_i+e_i`, with one hidden Haar O, `y_i~D_(L(B),s)` and `e_i~G_sigma`. Its null has the same B/profile law and independent `G_tau_N`, where `tau_N²=s²+sigma²`. Samples are independent conditional on B,O. The old exact finite rotation reference is separately defined; its general observed-transcript approximation remains open. P4A proves a new finite implementation for its specific enlarged-width rational-input route; it does not certify that old reference.

**P1C-R-v1** is a new target: one admissible deterministic abstract rule F selects a rational SPD width matrix C before every polynomial sample schedule and distinguisher. The same canonical description is public in both worlds; null samples are conditionally iid with covariance C/(2pi). F is independent of hidden O and samples. No exact real-covariance equality or efficient selection/sampling is inferred. P1C-U-v1 drops only the description. The fixed-width specialization reproduces P1 sample laws; full computational interface equivalence additionally requires matched/recoverable public lambda. P1 remains unchanged.

The historical encoder has a separately proposed **HIST-v3** law: `Y=Q_b(O^T B X+E)`, `c=Q_b(Yu+e_enc)`, integer independently sampled columns X, uniform sign vector u, and a detector verifying a bounded-distance residual. This settles definitions and lattice membership, not feasibility. P2 now supplies a reviewed fine-relative-precision incompatibility and explicit error/rejection
budgets; useful joint covertness, Gaussian-null rejection and efficient
subroutines remain [open](notes/project-map/RECORDS.md#r-p1-operations). Every valid key accepts zero; full-law acceptance at zero is the setup-success probability. Thus a correct instantiation cannot satisfy standard fixed-word soundness at zero.

Keep lambda, dimension n, NHR samples m, challenge count t, precision b, norm radius R, squared energy R², and decoding thresholds distinct. Gaussian width s has per-coordinate variance `s²/(2pi)`. Application cover width tau_C is independent of the NHR comparison width by definition. Public finite Enc implementations permit polynomial local calls beyond the challenger count t; no free exact ideal-reference encoder oracle is supplied.
