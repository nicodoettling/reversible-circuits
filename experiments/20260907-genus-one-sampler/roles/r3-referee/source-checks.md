# Permitted primary-source checks

Accessed 2026-09-07 through the web tool. No prior project verdict was consulted.

1. Ravi Vakil, *Genus 0 and 1 Hurwitz numbers: recursions, formulas, and graph-theoretic interpretations*, dated July 3, 2000, [primary PDF](https://math.stanford.edu/~vakil/files/g01hurwitz.pdf). Checked printed pages 3–4 (PDF pages 2–3), §1.2 and Corollary 1.5. The definition c^g_alpha counts transitive ordered transposition factorizations of a fixed permutation, with r=d+l(alpha)+2g-2. Its relation to the displayed cover count is c^g_alpha=G^g_alpha product alpha_i. Substituting this factor yields the formulas used in blind_report.md and check.py. The source distinguishes labeled parts and gives e_j as the elementary symmetric polynomial. No conjugacy-class factor, vertex-label quotient, or cycle-automorphism divisor belongs in our c count. Opposite product order is harmless for these counts: reversal inverts the endpoint and a permutation and its inverse have identical cycle lengths; actual algorithm multiplication is fixed separately.
2. E. Duchi, D. Poulalhon, G. Schaeffer, [*Uniform random sampling of simple branched coverings of the sphere by itself*](https://www.irif.fr/~poulalho/Articles/DuPoSc13.pdf). Checked title/abstract, introduction, Proposition 3 and Corollary 2. This source supplies a genus-zero identity sampler and uses the displayed order tau_m...tau_1. It is not an input theorem for the construction here. Its warning about exponential uncompressed cut-and-join generation motivated an explicit allocation-DP proof.
3. E. Duchi, D. Poulalhon, G. Schaeffer, [*Bijections for simple and double Hurwitz numbers*](https://arxiv.org/pdf/1410.6521), arXiv:1410.6521v1, 23 October 2014. Checked title, abstract, introductory scope only. No bijection or algorithmic theorem from this source is used.
4. B. Dubrovin, D. Yang, D. Zagier, [*Classical Hurwitz numbers and related combinatorics*](https://people.mpim-bonn.mpg.de/zagier/files/tex/ClassicalHurwitz/HurwitzRevised.pdf). Checked title, introductory generating-series normalization, and announced computational scope. No theorem from this source is used.

Vakil's formula is the only external mathematical dependency. This review checked the theorem statement, normalization, scope, and the product convention translation; it did not reprove the algebraic-geometric derivation of that published theorem. Web text extraction was sufficient for the formulas. Screenshot calls were attempted but did not expose a viewable image in this tool environment; no visual inspection is claimed.
