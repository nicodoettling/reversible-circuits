# M211 Plan — Interval-Kernel Boundary Edit

## Objective

Prove the standalone IKBE lemma from the exact M199/M207 literal tuple law,
or give the first exact counterexample and a rigorously corrected bound.
The two required clauses are:

    sum_(s=1)^(k-2) sqrt(s)
      |Phi_(s+1)^D(Z)-Phi_s^D(Z)| <= C sqrt(l),

and

    |Phi_s^D(Z)-Psi_s^D(Z)| <= C sqrt(l)/k

for Z=X_l,Y_l, odd k>=3, and 2<=l<=(3k-1)/2.
