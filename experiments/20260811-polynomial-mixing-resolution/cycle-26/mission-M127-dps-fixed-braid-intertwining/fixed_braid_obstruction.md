# DPS adjacent-value maps descend, but no fixed braid intertwines them

Date: 2026-08-13 UTC.

## 1. Scope, target, and convention

For `d>=2`, let

```text
Z_d={w=(t_1,...,t_(2d-2)):t_1...t_(2d-2)=id,
                              support(w) connected on [d]}.
```

Permutations compose as `(pq)(x)=p(q(x))`, and displayed factors multiply
left-to-right.  The signed right Hurwitz actions are

```text
R_j(...,a,b,...)    =(...,b,bab,...),
R_j^(-1)(...,a,b,...)=(...,aba,a,...),
```

because every factor is a transposition.  M112/M119 provide the accepted DPS
bijections

```text
Z_d <-> unrooted Hurwitz trees,
rooted Z_d <-> Cayley_d x S_(2d-2),
```

with exactly `d` rooted preimages of every physical word.  We use their
accepted `+` mirror and root the Cayley tree at `y_d`.

For `m=2d-2`, write `F(T,pi)` for the physical word produced by the rooted
DPS construction.  Let `s_i pi` mean that the **values** `i,i+1` are
interchanged wherever they occur in `pi`, for `1<=i<m`.

The proposition tested here is:

> For every `d,i`, there is one signed Hurwitz word `beta_(d,i)`, depending
> only on `d,i`, such that
> `beta_(d,i) F(T,pi)=F(T,s_i pi)` for every rooted DPS source `(T,pi)`.

This proposition is **REFUTED at `d=3`**.

## 2. The endpoint edit does descend through root forgetting

### Proposition 2.1 (unrooted adjacent-label involution; **PROVED**)

For every `d>=2` and `1<=i<2d-2`, there is a well-defined involution

```text
tau_i:Z_d -> Z_d,
tau_i(F(T,pi))=F(T,s_i pi).                              (2.1)
```

In particular, all `d` rooted coordinates over the same physical word give
the same target.  No white-root metadata is needed to define the endpoint.

**Proof.**  DPS Proposition 3 obtains a rooted Hurwitz tree by inserting the
black vertex `x_k` in the first parent edge from `y_k` to the chosen root and
putting edge labels `pi(2k-1),pi(2k)` on its two halves.  Replacing `pi` by
`s_i pi` therefore does exactly one intrinsic operation on that rooted
Hurwitz tree: exchange the two global edge labels `i,i+1`.  Relabeling edges
commutes with forgetting the white root.  Hence two rooted coordinates which
forget to the same unrooted Hurwitz tree still agree after this label
exchange.  The accepted unrooted DPS bijection then gives one physical target
in `Z_d`.  Exchanging the same labels twice is the identity, so `tau_i` is an
involution.  QED.

This distinguishes the obstruction below from a root-fiber collision.  The
arbitrary source-independent permutation `tau_i` of `Z_d` exists.  The claim
that it is one element of the signed Hurwitz action image is false.

## 3. A paired-source invariant for every fixed braid

### Lemma 3.1 (diagonal Hurwitz generated-subgroup invariant; **PROVED**)

Let `G` be any group, and let

```text
x=(x_1,...,x_m),   y=(y_1,...,y_m) in G^m.
```

If the same signed Hurwitz word `beta` is applied to both tuples, then

```text
< (x_1,y_1),...,(x_m,y_m) >
=< ((beta x)_1,(beta y)_1),...,((beta x)_m,(beta y)_m) >  (3.1)
```

as literal subgroups of `G x G`.

**Proof.**  Package the two sources into the `G x G` factor tuple

```text
((x_1,y_1),...,(x_m,y_m)).
```

One diagonal action `R_j` is exactly the ordinary Hurwitz action in `G x G`:

```text
(a,b) -> (b,b^(-1)ab)
```

for the two neighboring `G x G` factors.  The replacement generates the same
subgroup because both new factors lie in `<a,b>`, while
`a=b(b^(-1)ab)b^(-1)` lies in the subgroup generated by the new factors.
The inverse action has the same property.  Iterate over `beta`.  QED.

Consequently, a pair of sources whose required targets generate a different
coordinate-pair subgroup refutes **every** common signed Hurwitz word,
regardless of length.  This is stronger than a bounded-depth search.

## 4. A hand-checkable `d=3` contradiction

### Proposition 4.1 (fixed-braid intertwining; **REFUTED**)

Take `d=3`, adjacent value index `i=3`, and the Cayley star

```text
T={{1,2},{1,3}},
```

rooted at `y_3`.  In the accepted `+` mirror, the two exact rooted DPS rows

```text
pi_A=(3,4,1,2),       s_3 pi_A=(4,3,1,2),
pi_B=(1,2,4,3),       s_3 pi_B=(1,2,3,4)
```

close to

```text
x =F(T,pi_A)    =((12),(12),(13),(13)),
y =F(T,pi_B)    =((12),(13),(12),(23)),
x'=F(T,s_3 pi_A)=((23),(23),(13),(13)),
y'=F(T,s_3 pi_B)=((13),(13),(12),(12)).                (4.1)
```

There is no signed Hurwitz word which simultaneously sends `x` to `x'` and
`y` to `y'`.  Hence no universal `beta_(3,3)` exists, and the proposition in
Section 1 is false.

**Proof.**  Put `A=(12)`, `B=(13)`, and `C=(23)`.  The coordinate pairs of
the two sources are

```text
(A,A), (A,B), (B,A), (B,C).                            (4.2)
```

Every generator in (4.2) has equal sign in its two coordinates, so their
subgroup lies in

```text
H={(p,q) in S_3 x S_3 : sgn(p)=sgn(q)},   |H|=18.
```

Moreover `(A,A)^(-1)(A,B)` is `(id,AB)`, with `AB` a nontrivial 3-cycle,
and `(A,A)^(-1)(B,A)` is `(AB,id)`.  These generate `A_3 x A_3`; adjoining
`(A,A)` gives all of `H`.  Thus the source subgroup has order 18.

The target coordinate pairs reduce to the two generators

```text
(C,B), (B,A).                                          (4.3)
```

Let `rho=(123)`, viewed as the relabeling `1->2->3->1`.  Then

```text
rho C rho^(-1)=B,       rho B rho^(-1)=A.
```

Since `B,C` generate `S_3`, (4.3) generates precisely the graph subgroup

```text
K={(p,rho p rho^(-1)):p in S_3},        |K|=6.          (4.4)
```

The source and target coordinate-pair subgroups have different orders, in
contradiction with Lemma 3.1.  QED.

The formulas (4.1) were reconstructed by the independent hairy-tree closure
implementation in `fixed_braid_audit.py`; the subgroup orders `18` and `6`
were also enumerated directly.  The displayed argument makes the obstruction
independent of trusting a braid-depth cutoff.
