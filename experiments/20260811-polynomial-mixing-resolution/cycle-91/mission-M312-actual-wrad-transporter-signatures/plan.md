## Candidate fixed before computation

The sole candidate is the following **hierarchical signature conditional
agreement lemma (HSCA)**; it is not an RCOM pair-overlap or moment condition.

For a compatible ordered pivot tuple `I=(P_1,...,P_t)`, let

```text
T_I={s in S:x_P^s=y_P for all P in I},
```

choose `s_I in T_I`, and put

```text

z_Q^I=y_Q^(s_I^(-1)),
D_I(Q)={h in H_I:x_Q^h=z_Q^I}.
```

The forced-true signature cell is

```text
F(I,s_I)={Q in M:D_I(Q)=H_I}.
```

HSCA asserts that universal constants `C_1,C_2` exist such that, for every
actual `d>=6` matching and every nonzero `lambda>=0`, one can choose a
positive-weight anchor and a compatible pivot tuple containing it with

```text
t<=C_1 log d,
sum_(Q in F(I,s_I))lambda_Q
  >= ||lambda||_1/d^C_2.                            (HSCA)
```

Every completion `h;s_I`, `h in H_I`, then agrees with the entire forced
cell, so HSCA would imply WRAD.  The bounded pivot depth is an explicit
polynomial hierarchical certificate, not an average of pair intersections.
