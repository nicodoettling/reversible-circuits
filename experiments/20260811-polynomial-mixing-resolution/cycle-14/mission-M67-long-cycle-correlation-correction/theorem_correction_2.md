# M67 theorem correction 2: ordered positions

Date: 2026-08-12. This append-only wording correction supersedes the phrase
`for every i!=j` immediately before equation (1.2) of frozen `theorem.md` by

```text
for every ordered pair of positions i<j.
```

With this convention, the fixed factors occur as `e` then `f`, and the class
sum coefficient is exactly `[h_n]efT^(n-3)`. If `i>j`, the corresponding
formula has the positional order `fe`; no later argument uses that ordering.
All definitions of `c_n`, all four cross terms in the paired products, and the
Gram witness use increasing raw positions, so no equation or conclusion is
changed.
