# Stabilizer-voltage coset theorem

## Status and conventions

**Proved.** Let `d >= 3`. Let `Z_d` be the set of connected, product-one,
length `2d-2` transposition words, with the literal signed Hurwitz action of
the braid group `B = B_(2d-2)`. Simultaneous relabeling by `G = S_d`
commutes with the Hurwitz action. Because every word in `Z_d` generates
`S_d` and the centralizer of `S_d` in itself is trivial, the relabeling
action is free. Put `Q_d = Z_d/G`.

For an ordered width-`s` tuple use

```text
X = Z_d^s,       Y = Q_d^s,       N = G^s,
W_s = F_2^s / Delta,   Delta = <(1,...,1)>.
```

The one braid acts diagonally on all `s` coordinates, whereas `N` relabels
the coordinates independently. Products below use a left action. Thus in
`b_2 b_1`, the braid `b_1` acts first.

## Cocycle and stabilizer voltage

Choose a section `sigma:Y -> X`. Freeness gives a unique `c(b,q) in N`
such that

```text
b sigma(q) = c(b,q) sigma(bq).
```

Let `epsilon:N -> F_2^s` record permutation parity coordinatewise and let
`pi:F_2^s -> W_s` be the quotient map. Define

```text
nu(b,q) = pi(epsilon(c(b,q))).
```

### Lemma 1 (groupoid cocycle)

For all `b_1,b_2 in B` and `q in Y`,

```text
nu(b_2 b_1,q) = nu(b_1,q) + nu(b_2,b_1 q).
```

**Proof.** The two actions commute, so

```text
b_2 b_1 sigma(q)
 = c(b_1,q)c(b_2,b_1q) sigma(b_2b_1q).
```

Apply coordinatewise parity and then `pi`. (The nonabelian transporter
order disappears only after applying parity.) QED.

For the point stabilizer

```text
B_q = {h in B : hq=q},
```

Lemma 1 says that `h |-> nu(h,q)` is a homomorphism. Define

```text
V_stab(q) = nu(B_q,q) <= W_s.
```

Equivalently, for any physical lift `x in X` of `q`, each `h in B_q` has a
unique transporter `rho_x(h) in N` with `hx=rho_x(h)x`, and

```text
V_stab(q)
 = { pi(epsilon(rho_x(h))) : h in B_q }.
```

This is an intrinsic point-stabilizer characterization; no choice of
generators for the full quotient image is required.

### Theorem 2 (exact endpoint-coset criterion)

Let `q,r in Y`, and suppose the quotient route set

```text
R(q,r) = {b in B : bq=r}
```

is nonempty. For any fixed `b_0 in R(q,r)`,

```text
{nu(b,q) : b in R(q,r)} = nu(b_0,q) + V_stab(q).
```

In particular, a zero-relative-voltage quotient route exists if and only if

```text
nu(b_0,q) in V_stab(q),
```

or, equivalently, if and only if the displayed affine coset contains zero.

**Proof.** Every route has the unique form `b=b_0h` with `h in B_q`.
Lemma 1 gives

```text
nu(b_0h,q) = nu(h,q)+nu(b_0,q).
```

As `h` ranges over `B_q`, its first term ranges over exactly
`V_stab(q)`. QED.

The same coset may be written using the target stabilizer. Conjugation by
`b_0` identifies `B_q` with `B_r`, and a direct use of Lemma 1 (including
the inverse identity) shows `V_stab(q)=V_stab(r)` inside the fixed group
`W_s`.

## Dependence on lifts and sections

If `sigma'(q)=a(q)sigma(q)`, then, writing
`alpha(q)=pi(epsilon(a(q)))`,

```text
nu'(b,q) = alpha(q)+nu(b,q)+alpha(bq).
```

Consequently `V_stab(q)` is section-independent: the two endpoint terms
cancel on a loop. In contrast, the route coset from `q` to `r` is
translated by `alpha(q)+alpha(r)`. Therefore the bare assertion that its
coset contains zero is not invariant under arbitrary independent changes of
the endpoint representatives. It is meaningful for the fixed physical
source and target representatives in M135; it is also unchanged when the
same coordinatewise relabeler is applied to both members of a matched pair.

More generally, if `x=n_x sigma(q)` and `y=n_y sigma(r)` are specified
physical endpoints, literal equality `bx=y` requires

```text
c(b,q)=n_x^(-1)n_y.
```

The corresponding parity requirement transforms by the same coboundary as
the cocycle, so the physical criterion itself is section-independent.

## Relation to the M154 inner-conjugation loops

Accepted M154 constructs a fixed braid loop which, on every product-one
word, realizes simultaneous conjugation by a chosen current factor. On an
aligned `s`-tuple, compositions of these loops realize conjugation by the
subgroup generated by its aligned factor tuples. Accepted M141 identifies
that subgroup as

```text
P_(d,s) = { (g_1,...,g_s) in S_d^s :
            sign(g_1)=...=sign(g_s) }
```

for the stated `d>=5` matching subfamilies. Every element of `P_(d,s)` has
diagonal parity and hence maps to zero in `W_s`. These loops lie in the
kernel of stabilizer voltage; they do **not** supply nonzero voltage.

Thus there are two separate obligations:

1. find a quotient braid with the required affine voltage class, governed
   exactly by Theorem 2; and
2. after its relative voltage is zero, use an inner `P_(d,s)` loop to correct
   the remaining literal transporter.

The first is the M163 stabilizer-voltage problem. Polynomial quotient word
length and polynomial/short inner-transporter length are additional,
separate obligations.

## First unresolved general lemma

For the accepted ordered M135 matching subfamilies and every `d>=5`, decide
whether

```text
V_stab(q) = W_s.
```

The coset theorem neither proves this equality nor proves that a polynomial-
length braid realizes each voltage. No Conway--Parker/Nielsen completeness
classification is invoked here.
