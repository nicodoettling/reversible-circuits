# M141 plan: multisource subgroup audit for one matching color

Date: 2026-08-13 UTC.

## Objective

Continue only the accepted M135/M137 **POLYNOMIAL MATCHING-COSET
REFINEMENT** frontier.  Fix `d>=5`, an adjacent DPS edit `tau_i`, and one
perfect-matching color in M135's root-stabilizer orbit-incidence multigraph.
Choose one physical source representative for every edge in that matching.
Determine the exact subgroup of `S_d^r` generated by the positionwise source
tuples, and do the same for the corresponding target representatives.

The candidate theorem is that both groups equal

```text
P_(d,r)={(g_1,...,g_r) in S_d^r:
                       sgn(g_1)=...=sgn(g_r)}.
```

If true, every invariant depending only on the subgroup generated by any
number of selected source coordinates is automatically passed by the DPS
edit.  This would be a negative sharpening of the obstruction search, not a
simultaneous-braid theorem.

## Convention and target

The auxiliary target is uniform on

```text
Z_d={(t_1,...,t_(2d-2)):t_1...t_(2d-2)=id,
                              support connected on [d]}.
```

Permutations compose as `(pq)(x)=p(q(x))`; displayed factors multiply
left-to-right.  Signed right-Hurwitz moves are

```text
R_j(a,b)=(b,bab),       R_j^(-1)(a,b)=(aba,a).
```

No Markov kernel or spectral gap is bounded in this mission.

## Work program

1. Audit that distinct matching edges have representatives in distinct
   source `S_d`-conjugacy orbits and targets in distinct target orbits.
2. Use M135's pair dichotomy to identify every two-coordinate projection.
3. Intersect the multisource group with `A_d^r` and prove or refute that a
   pairwise-full subdirect subgroup of a direct power of nonabelian simple
   `A_d` is the full direct power.  Treat `d=5` and `d=6` explicitly.
4. Recover the odd parity coset and identify the whole common-parity group.
5. Audit arbitrary subfamilies, the `r=1` edge case, and exceptional ranks
   `d=2,3,4`.  Use a deterministic exact checker only for named finite
   falsification/calibration questions.
6. State the exact remaining simultaneous action-coset intersection and
   polynomial braid-length obligation.

## Expected failure modes

- Pair projections of the even kernel need not be full.
- Pairwise-full subdirect products may retain a hidden diagonal block
  coupling, especially through exceptional automorphisms at `d=6`.
- A matching may fail to put representatives in distinct global orbits.
- The full matching theorem may hold while some stronger arbitrary-family
  statement fails.
- Generated-subgroup equality may be necessary but is not sufficient for a
  common signed braid.

## Reproducibility and scope

The exact checker, if used, is deterministic (`seed=null`), standard-library
Python 3 only, and records machine-readable output.  No M135/M137 or shared
project file will be edited.  No UST route, all-edge comparison, physical
gap, arbitrary-product `Gamma_0`, original heat-bath gap, Terminal A, or
Terminal B claim is in scope.
