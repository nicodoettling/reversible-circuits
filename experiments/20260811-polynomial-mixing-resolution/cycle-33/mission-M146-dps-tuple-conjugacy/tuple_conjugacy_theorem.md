# Common-parity conjugacy and the DPS aligned-factor invariant

Date: 2026-08-13 UTC.

## 1. Scope, target, and convention

For `d>=2`, put `m=2d-2` and

```text
Z_d={(t_1,...,t_m):t_1...t_m=id,
                         support connected on [d]}.
```

The auxiliary target is uniform on `Z_d`. Permutations compose as
`(pq)(x)=p(q(x))`, and displayed factors multiply left-to-right. Signed
right-Hurwitz generators are

```text
R_j(a,b)=(b,bab),       R_j^(-1)(a,b)=(aba,a)
```

for transpositions. This note classifies the necessary aligned-factor
conjugacy invariant and proves that it is automatic in every `d>=5` M135
matching subfamily. It does not prove a common braid.

## 2. Exact conjugacy classification in the common-parity group

Fix `s>=1`. Write

```text
G_(d,s)=S_d^s,
P_(d,s)={(g_1,...,g_s):sgn(g_1)=...=sgn(g_s)}.
```

Use additive parity vectors

```text
sigma:G_(d,s)->F_2^s
```

and let `Delta={(e,...,e):e in F_2}`. Thus
`P_(d,s)=sigma^(-1)(Delta)`.

For `x=(x_1,...,x_s) in P_(d,s)`, call coordinate `q` **rigid** when

```text
C_(S_d)(x_q) <= A_d.                                  (2.1)
```

Let `R(x)` be the set of rigid coordinates and `r(x)=|R(x)|`.

### Lemma 2.1 (centralizer parity; **PROVED**)

For `p in S_d`, its centralizer contains no odd permutation if and only if
the cycle type of `p` consists of distinct odd parts.

**Proof.** If `p` has an even cycle, that cycle is itself odd and belongs to
the centralizer. If two cycles have the same odd length `ell`, the
permutation interchanging them point by point is a product of `ell`
transpositions, hence is odd, and centralizes `p`. These two cases also cover
repeated even lengths, using the even cycle itself, and repeated fixed points,
using their transposition.

Conversely, if all cycle lengths are odd and distinct, no equal-length cycles
can be permuted. The centralizer is the direct product of the cyclic groups
generated by the individual cycles. Every odd cycle is an even permutation,
so the entire centralizer lies in `A_d`. QED.

### Theorem 2.2 (exact `P_(d,s)` conjugacy criterion; **PROVED**)

Let `x,y in P_(d,s)` be conjugate in `G_(d,s)`. Choose any
`g=(g_1,...,g_s) in G_(d,s)` with

```text
g x g^(-1)=y.                                         (2.2)
```

For a rigid coordinate `q`, the parity `delta_q=sgn(g_q)` is independent
of the choice of `g_q`. Then

```text
x and y are conjugate in P_(d,s)
iff all delta_q, q in R(x), are equal.                 (2.3)
```

If `R(x)` is empty or a singleton, the condition is vacuous. Moreover, the
single ambient `G_(d,s)` conjugacy class containing `x` splits into exactly

```text
2^max(r(x)-1,0)                                       (2.4)
```

conjugacy classes under `P_(d,s)`.

**Proof.** Every transporter from `x` to `y` is in the coset
`g C_G(x)`, where

```text
C_G(x)=product_q C_(S_d)(x_q).
```

At a nonrigid coordinate the centralizer contains both parities, so the
parity of the coordinate transporter can be flipped independently. At a
rigid coordinate every centralizer element is even, so `delta_q` is
well-defined and cannot be changed. A transporter lies in `P_(d,s)` exactly
when all coordinate parities agree. This is possible exactly under (2.3).

For the count, let `B<=F_2^s` be the parity image of `C_G(x)`. It is the
coordinate subspace supported on the nonrigid coordinates. Since `P` is
normal in `G`, the number of `P`-orbits inside the ambient class is

```text
[G:P C_G(x)]=[F_2^s:Delta+B].                         (2.5)
```

If there are `r>=1` rigid coordinates, `Delta+B` has dimension
`s-r+1`, so (2.5) is `2^(r-1)`. If `r=0`, then `B=F_2^s` and the index
is one. This is (2.4). QED.

### Corollary 2.3 (all-odd classes do not split; **PROVED**)

If `x in P_(d,s)` is all-odd, then its ambient `G_(d,s)` conjugacy class is
a single `P_(d,s)` conjugacy class.

**Proof.** Each odd coordinate `x_q` is itself an odd element of its own
centralizer. Hence `R(x)` is empty, and Theorem 2.2 applies. QED.

### Corollary 2.4 (one class of transposition tuples; **PROVED**)

For every `d>=2` and `s>=1`, all tuples

```text
(t_1,...,t_s),  each t_q a transposition in S_d,
```

form one conjugacy class in `P_(d,s)`.

**Proof.** They are all-odd. They are coordinatewise conjugate in `S_d^s`,
because all transpositions in `S_d` are conjugate. Corollary 2.3 finishes
the proof. Explicitly, each coordinate transporter can be made even by
multiplying an odd transporter by the source transposition in its
centralizer; the tuple of even transporters belongs to `P_(d,s)`. QED.

This includes `s=1`, where `P_(d,1)=S_d`, and `d=2`, where there is only
one transposition.

## 3. Why a common braid preserves this multiset

Choose `s` source words `u^1,...,u^s` and align factor position `j` as

```text
x_j=(u_j^1,...,u_j^s) in S_d^s,
Gamma_U=<x_1,...,x_m>.                                (3.1)
```

A common right-Hurwitz generator sends

```text
(x_j,x_(j+1)) ->
(x_(j+1), x_(j+1)^(-1) x_j x_(j+1)).                 (3.2)
```

Thus it permutes one factor and replaces the other by a conjugate inside
`Gamma_U`. The inverse generator has the same property. It follows that a
common signed braid preserves both `Gamma_U` literally and the multiset

```text
M_U={{ [x_1]_(Gamma_U),...,[x_m]_(Gamma_U) }}.         (3.3)
```

This is a **PROVED necessary** condition. No sufficiency is asserted.

## 4. Application to every M135 matching

Fix `d>=5`, an adjacent DPS edit `tau_i`, an arbitrary matching in M135's
orbit-incidence multigraph, and any nonempty subfamily `I` of `s` edges.
Choose arbitrary physical representatives `u^q`, put
`v^q=tau_i(u^q)`, and form aligned source and target factors

```text
x_j=(u_j^q)_(q in I),       y_j=(v_j^q)_(q in I).      (4.1)
```

The accepted M141/M143 theorem gives

```text
Gamma_U=Gamma_V=P_(d,s).                              (4.2)
```

Every coordinate of every `x_j` and `y_j` is a transposition. Corollary
2.4 therefore puts all of them in one `P_(d,s)` conjugacy class, call it
`T_(d,s)`. Since both words have `m=2d-2` factor positions,

```text
M_U=M_V=(2d-2) copies of [T_(d,s)].                   (4.3)
```

### Theorem 4.1 (DPS tuple-conjugacy invariant is automatic; **PROVED**)

For every `d>=5`, every adjacent DPS edit, every M135 matching, every
nonempty matching subfamily, and every choice of physical representatives,
the source and target aligned-factor conjugacy-class multisets inside their
generated group are equal. The descriptor is constant, so the matching needs
no refinement for this invariant.

Theorem 4.1 is a negative sharpening of the simultaneous-realization
frontier. It eliminates this necessary invariant as a source of a
counterexample or a useful polynomial refinement. It does not show that the
action cosets intersect or that a common braid of any length exists.

## 5. Exact rank-three calibration

The deterministic checker reconstructs all nine accepted M137 matchings at
`d=3` (three adjacent edits and three deterministic colors), each with four
edges, and checks all fifteen nonempty subfamilies. It first compares the
literal source and target generated groups. Only when these groups are equal
does it compare conjugacy multisets inside that common group.

```text
width  literal groups equal and class multisets equal  literal groups differ
1      36                                               0
2      54                                               0
3       3                                              33
4       0                                               9
```

There are zero class-multiset changes among the `93` literal-group-equal
subfamilies. Thus at `d=3` this invariant adds no obstruction beyond the
already recorded multisource subgroup changes. This is an **exact finite
fact**, not an input to the `d>=5` proof.

At `d=4`, M135/M137 already has a paired-subgroup exception and uses
singleton colors. Theorem 4.1 deliberately starts at `d=5`; the stand-alone
conjugacy classification itself remains valid at `d=4`.
