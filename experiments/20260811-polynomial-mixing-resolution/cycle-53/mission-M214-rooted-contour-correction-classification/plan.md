# M214 plan: rooted-contour correction classification

## Objective

Classify the exact physical correction needed when the declared d=5 rooted
DPS coordinate is extended by one new leaf. M208/M212 proved seven correction
words for two trees but refuted their universality on the full 16-tree
template. The new target is a finite local descriptor whose classes cover all
16 trees and seven inherited edits and carry explicit common signed-Hurwitz
correction words.

## Immutable gate

Verify full frozen inventories of M203/M205 and M208/M212 before substantive
dependence. Never edit predecessor missions.

## Classification program

1. Reconstruct the 16 trees with old root 5 a leaf adjacent to vertex 1, the
   common orders `pi_5,pi_6`, and all 112 naive/actual endpoint rows.
2. For each edit, identify the black slots/factor labels affected by
   `s_i`, their attachment vertices, ancestor relations, and their positions
   relative to the rerooting contour `5-1-6`.
3. Propose progressively refined local keys. For each key, test whether one
   signed-Hurwitz word realizes every row in that class using targeted
   diagonal tuple search and exact replay.
4. If a key fails, seek an exact paired/tuple action invariant or archive the
   first incompatible rows and refine. Avoid singleton row keys unless the
   local data intrinsically distinguishes them.
5. Freeze the smallest exact finite classification obtained, or the sharpest
   same-key obstruction.

## Computation bounds

No Q6 quotient enumeration. Searches may explore only diagonal actions on
the named endpoint tuples, with explicit caps and positive words archived.
Radius misses have no negative interpretation.

## Scope exclusions

This mission is exact finite d5-to-d6 only. It does not imply a general-d
recurrence, arbitrary matching-color or H-representative routing, polynomial
route or voltage-correction length, spectral gap, mixing, or Terminal.

## Deliverables

Initialization/hash/halfway checkpoints, compact checker/results, exact
classification theorem or obstruction, nine-field report, hashes/manifest,
and fresh-audit request.
