# M291 Plan: Chartless Base-Route Signatures

## Role and immutability

M291 owns only this mission directory. It will not edit predecessors,
coordinator files, the manuscript, the project skill, `HANDOFF.md`,
`GOAL_SPEC.md`, `AGENTS.md`, or another worker's directory.

## Objective

Advance exactly the first open interface left by M284/M288:

> Construct, or sharply obstruct, a polynomial-cardinality base-route
> signature cover that includes chartless global orbits and the actual
> `H`-orbit edge selected by an arbitrary M135 perfect-matching color.

The first constructive target is a canonicalization of an arbitrary word in
the connected minimal identity sector to a valid doubled-tree
rank-extension chart by an explicit signed braid word of polynomial length.
The second target is the exact additional data needed so one literal braid
schedule works simultaneously on a family of matching-selected
root-stabilizer orbit edges.

## Target and type discipline

The ambient sampler target remains the global fixed-length uniform bridge
law on

```text
Omega(N,m)={transposition words of length m with product identity}.
```

This mission studies only deterministic routing in the minimal connected
sector `Z_d`, where `m=2d-2`. It will keep separate:

- literal signed braid elements and explicit representatives;
- finite braid-action images;
- global `G=S_d` orbits;
- root-stabilizer `H`-orbit edges selected by a matching color; and
- old-padded/new-rank local corrections.

No Markov kernel, probability estimate, or gap claim is made here.

## Proof program

1. Recover the exact minimal-sector structural normal form and the accepted
   Hurwitz conventions without assuming unverified global transitivity.
2. Seek a constructive reduction of an arbitrary connected minimal identity
   word to a consecutive doubled-tree word. Track signed generators,
   polynomial length, global relabeling, root choice, and every noncanonical
   branch.
3. Translate the result into M135's selected root-stabilizer-edge language.
   Determine whether a canonicalization can be chosen uniformly on
   polynomially many signature classes, rather than separately per source.
4. Express each class as a literal base-route fiber whose terminal chart can
   feed M284's rank lift. Check intersections before passing to finite action
   images.
5. If a polynomial common cover follows, freeze the explicit exponent and
   exceptional ranks. Otherwise name a compressed signature, construct an
   arbitrary-rank collision with incompatible future schedules, and freeze
   the strict obstruction or the narrowest exact reduction.
6. Permit at most one compact `d=5` or `d=6` guard after formulas are
   fixed. No broad state-space enumeration or route search is allowed.

## Expected failure modes

- Using qualitative Hurwitz transitivity as a polynomial-length algorithm.
- Canonicalizing each source with a different word and then calling it a
  common schedule.
- Forgetting that a color selects an arbitrary root-stabilizer orbit edge over each
  global orbit, not a preferred rooted representative.
- Quotienting braid words to actions before proving a representative-length
  bound.
- Treating M284's `q -> 2q` local lift as a full-color recurrence despite
  chartless sources.

## Deliverables and verdict rule

- `checkpoint.md` with the halfway frontier.
- A theorem/reduction/obstruction note with explicit definitions and
  boundary cases.
- At most one compact no-predecessor-import guard and machine-readable
  output, only if needed.
- `report.md` with a `promote`, `keep`, `reject`, or
  `inconclusive` verdict, the first remaining lemma, and numbered
  qualifications.
- A freeze manifest and SHA-256 inventory, followed by a fresh audit
  request.

No every-color theorem is accepted unless an actual full-color intersection
with polynomial representatives is proved. No voltage, congestion, gap,
mixing, or Terminal statement is permitted.
