# Explicit marked-set scope for `report.md`

For a two-component exterior macro `Gamma`, M75's marked set `G_Gamma`
consists exactly of states with a globally adjacent square in the genus-one
component such that deleting those two occurrences leaves that genus-one
component connected. Every use of “marked” or “marked row” in `report.md`
has this meaning.

The zero-row theorem applies to this literal set. After adjoining a disjoint
doubled edge to `W_L`, the second component is nontrivial, but a square in it
does not count as a `G_Gamma` mark because it is the genus-zero component.
