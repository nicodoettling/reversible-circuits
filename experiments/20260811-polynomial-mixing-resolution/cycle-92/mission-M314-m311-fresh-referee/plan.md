# Mission M314 plan: fresh immutable referee for M311

## Referee posture

This directory is the sole write scope for M314.  The frozen M311 package and
all predecessors are read-only evidence.  M311 remains unopened at the time
this plan is created.

## Objective

Independently accept or reject frozen M311 after checking:

1. the pinned top `SHA256SUMS` digest
   `a022f56fc8f66dd4ea4d5a07b355e5e7612b57bb537c29fb3f94120cc155f842`;
2. every frozen M311 payload and every dependency cited by M311;
3. the exact QBD staircase, rung, and sign-block identity;
4. the claimed sufficiency of QBP;
5. exactly one independent reconstruction of the frozen `k=11`
   first-failure case, including exact counts and all positive aggregate facts.

## Method

- Read the project source-of-truth documents and the complete
  reversible-circuit-sampler skill before substantive audit work.
- Verify hashes before treating frozen prose or data as evidence.
- Re-derive the algebra and quantifiers independently.
- Perform only the authorized `k=11` reconstruction, in this directory, with
  deterministic and reproducible code and machine-readable output.
- Record numbered material and nonmaterial objections, including an explicit
  empty list when none exist.
- Freeze the referee package with an inventory, hashes, and one top digest.

## Hard scope firewall

No new rank, alternate grouping, alternate search, all-rank inference, or
downstream theorem is authorized.  In particular, M314 will make no new
irreducibility, routing, voltage, congestion, spectral-gap, mixing, or
Terminal inference.  It will not edit M311, predecessors, coordinator files,
the manuscript, `HANDOFF.md`, `GOAL_SPEC.md`, `AGENTS.md`, or the project
skill.

## Decision rule

`ACCEPT` means every frozen payload/dependency is intact and every in-scope
claim survives an independent exact audit.  A material mathematical,
provenance, reproducibility, or scope defect forces `REJECT`; merely editorial
issues are listed as nonmaterial objections.
