# Reduced Pin lifting invariant for aligned transposition tuples

Date: 2026-08-13 UTC.

## 1. Scope and convention

Fix `d>=3`, `s>=1`, and

```text
P_(d,s)={(g_1,...,g_s) in S_d^s:
                         sgn(g_1)=...=sgn(g_s)}.
```

Let `C_(d,s)` be the set of all `s`-tuples of transpositions.  This lies in
`P_(d,s)`.  Package `s` physical identity words of common even length `m`
into aligned factors

```text
x_j=(t_j^1,...,t_j^s) in C_(d,s),  1<=j<=m.
```

The coordinatewise product of the `x_j` is identity.  Permutations compose as
`(pq)(x)=p(q(x))`, and signed right-Hurwitz moves are

```text
R_j(a,b)=(b,b^(-1)ab),
R_j^(-1)(a,b)=(aba^(-1),a).
```

For transpositions these agree with the project's displayed formulas.  The
result below concerns only a necessary invariant of a simultaneous signed
Hurwitz action.  It asserts no common braid.

## 2. An explicit Pin double cover

Let `Cl_d` be the real Clifford algebra generated by orthonormal vectors
`e_1,...,e_d`, with

```text
e_i e_j+e_j e_i=2 delta_(ij).
```

For `i<j`, put

```text
a_(ij)=(e_i-e_j)/sqrt(2).
```

Then `a_(ij)^2=1`.  The twisted adjoint action of `a_(ij)` on the vector
space is

```text
v -> -a_(ij) v a_(ij)
   = v-2<a_(ij),v>a_(ij),
```

which swaps `e_i,e_j` and fixes their orthogonal complement.  Therefore the
group generated by these root vectors and `z=-1` has a surjection

```text
1 -> {1,z} -> S~_d -> S_d -> 1,            (2.1)
```

with `a_(ij)` above `(ij)`.  The kernel is exactly the scalar units `+/-1`:
a product of unit vectors acting trivially by the twisted adjoint is a scalar,
and its Clifford norm is one.  This proves (2.1) directly from the algebra,
without importing a classification theorem for Schur covers.

Take the coordinate product of (2.1), restrict it above `P_(d,s)`, and write

```text
1 -> Z=<z_1,...,z_s> ~= F_2^s
  -> P~_(d,s) -> P_(d,s) -> 1.              (2.2)
```

Here `z_q` is `-1` in coordinate `q` and `+1` elsewhere.

## 3. The reduced class-lift construction

First observe that `C_(d,s)` is one `P_(d,s)`-conjugacy class.  Coordinatewise
transporters between transpositions can all be chosen even: if a transporter
is odd, multiply it on the right by the source transposition, which centralizes
the source and flips parity.  The tuple of even transporters belongs to
`A_d^s <= P_(d,s)`.

Fix `x in C_(d,s)` and a lift `x~`.  Define `K_C<=Z` to be generated by

```text
[x~,h~]=x~ h~ x~^(-1) h~^(-1),
     h in C_(P_(d,s))(x),                     (3.1)
```

where either lift of `h` may be used.  The commutator lies in `Z`, and changing
a lift by a central element does not change it.

In the quotient `P~_(d,s)/K_C`, the conjugacy orbit of the image of `x~` maps
bijectively onto `C_(d,s)`.  Indeed, two conjugators carrying `x` to the same
element differ by a centralizer element, and (3.1) kills exactly the resulting
lift ambiguity.  Denote this conjugacy-equivariant section by

```text
ell:C_(d,s) -> P~_(d,s)/K_C.
```

For a product-one sequence in `C_(d,s)`, define

```text
Lift(x_1,...,x_m)=ell(x_1)...ell(x_m) in Z/K_C.  (3.2)
```

This is independent of replacing the chosen base lift by `z_0 x~` when `m`
is even, because `Z` has exponent two.  In particular it is canonical for
the minimal-sector length `m=2d-2`.

### Lemma 3.1 (signed-Hurwitz invariance; PROVED)

The value (3.2) is unchanged by every signed right-Hurwitz move.

**Proof.** Conjugacy equivariance gives

```text
ell(b^(-1)ab)=ell(b)^(-1)ell(a)ell(b).
```

Thus the lifted product of the moved pair is

```text
ell(b)ell(b^(-1)ab)=ell(a)ell(b).
```

The inverse move is the inverse identity.  All other factors are unchanged.
QED.

Consequently unequal values of (3.2) obstruct a common signed braid.  Equal
values are only necessary and supply no realization.

## 4. Coordinatewise annihilation for `d>=4`

### Theorem 4.1 (reduced kernel is trivial; PROVED)

For every `d>=4`, every `s>=1`, and the transposition-tuple class
`C_(d,s)`,

```text
K_C=Z.
```

Hence the reduced Pin lifting invariant (3.2) has one possible value.

**Proof.** Write `x=(t_1,...,t_s)`.  Fix a coordinate `q`.  Because `d>=4`,
choose a transposition `v_q` disjoint from `t_q`.  Define `h^(q)` to have
coordinate `t_q v_q` at `q` and identity in every other coordinate.  Every
coordinate of `h^(q)` is even, so

```text
h^(q) in A_d^s <= P_(d,s).
```

Moreover `t_q v_q` centralizes `t_q`, so `h^(q)` centralizes `x`.

Let `a,b` be the Clifford root lifts of `t_q,v_q`.  The roots are orthogonal,
so

```text
a^2=b^2=1,       ab=-ba.
```

Use `ab` as the coordinate-`q` lift of `t_qv_q`.  In that coordinate,

```text
[a,ab]=a(ab)a^(-1)(ab)^(-1)
      =baba=-1.
```

All other coordinates commute trivially.  Thus (3.1) contains exactly `z_q`.
As `q` was arbitrary, it contains all generators of `Z`, proving `K_C=Z`.
QED.

The use of `h^(q)` is essential: it is an all-even element of the full
common-parity group and kills `z_q` individually.  An all-odd centralizer
would show at most a diagonal relation and would not prove the theorem.

### Corollary 4.2 (DPS matching consequence; PROVED)

For `d>=5`, every source and target aligned factorization arising from any
nonempty M135 matching subfamily automatically has the same reduced Pin
lifting invariant.  In fact this conclusion holds for arbitrary product-one
sequences in `C_(d,s)` and does not require the accepted M141 subgroup theorem.

This closes only this particular natural lifting descriptor negatively.

## 5. Boundary rank `d=3`

There is no disjoint-transposition centralizer at rank three, but the cover
itself splits.  Put

```text
a=(e_1-e_2)/sqrt(2),     b=(e_2-e_3)/sqrt(2).
```

Their inner product is `-1/2`, hence

```text
a^2=b^2=1,       ab+ba=-1.
```

Right multiplication of the last identity by `a`, and left multiplication
by `b`, give

```text
aba=-a-b=bab.
```

Thus `a,b` satisfy the Coxeter presentation

```text
<s_1,s_2 | s_1^2=s_2^2=1, s_1s_2s_1=s_2s_1s_2>
```

of `S_3`.  Mapping `s_1->a,s_2->b` defines a homomorphic section
`sigma:S_3->S~_3` because its projection is the identity.  Coordinatewise,
`sigma^s` restricts to a homomorphic section of (2.2) over `P_(3,s)`.

Choose the lifted transposition class inside this split copy.  For every
product-one aligned sequence,

```text
Lift(x_1,...,x_m)=sigma^s(x_1...x_m)=1.       (5.1)
```

Any other central translate of the lifted class gives the same value at the
minimal length `m=4`, since its translating element has fourth power one.
Thus the residual vector of coordinate signs is identically zero.  The exact
rank-three matching audit checks (5.1) on all accepted M135 matching
subfamilies.

## 6. Scope boundary

The theorem proves that the natural reduced Pin/Schur lifting invariant is
constant for the aligned transposition factorizations relevant here:
coordinatewise centralizer commutators annihilate it for `d>=4`, and the cover
splits over `S_3`.

It does **not** classify Nielsen classes, rule out every possible central
extension invariant of `P_(d,s)`, prove an action-coset intersection, construct
a common braid, bound braid length, or imply any Markov-chain gap.
