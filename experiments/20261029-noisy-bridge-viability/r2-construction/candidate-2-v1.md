# C2-v1: path/star gluing on a planted support, with polynomial Hurwitz scrambling

Frozen only AFTER candidate-1-rejection-v1.md. Status: fully specified candidate, not a security assertion. M0 target is complete Q_k output against Q_k of GLOBAL U(N,L), rightmost-first products. This is the second and final candidate in this role.

## Why the construction changed

C1 creates many bounded-length identity relators and uses too few adjacent moves to erase their visible windows. C2 creates ONE relation occupying the entire word, from two different factorizations of the same long cycle. Its fixed scrambling budget L^3 defeats the deterministic few-moves surviving-window premise. Its potential failure is instead a planted small support, which no number of Hurwitz moves changes. This is an explicit construction and support-obstruction test, not an assertion that pure Hurwitz draws correct global orbit weights.

## Parameters, setup, algorithm

Finite family: integers m>=2, N>=m+1, v=m+1, L=2m, s>=0, and 0<=k<=L. Public A=(N,m,s,k); no secret K. Fresh tapes on every request. Sample an ordered injection (a_1,...,a_v) uniformly from [N]. Emit

    (a_1 a_2), (a_2 a_3), ..., (a_(v-1) a_v),
    (a_1 a_2), (a_1 a_3), ..., (a_1 a_v).

Then apply s independent uniform signed adjacent Hurwitz moves, exactly the H_i/H_i^{-1} maps specified in C1-v1. Each chooses i uniformly in {1,...,L-1} and a fair independent sign. Output this word, after which M0 independently applies Q_k. No unmentioned postprocessing, random-key oracle, decoder or global uniform sampler is invoked.

Concrete polynomial schedule: lambda>=9 integer, m=lambda, N=lambda^6, L=2lambda, s=L^3, k=floor(sqrt(lambda)). Sampling needs no secret. Public data and setup are identical in both worlds. Reused setup only reuses these integers; all word and noise tapes are fresh. Expected runtime O(N+L+s) label operations for the reference list-based implementation (it materializes [N]); the algorithm also admits O(L+s) expected operations with sparse injection sampling. Memory O(N+L) in the supplied implementation, or O(L) with a sparse sampler. Either is polynomial in lambda,N,L. This is not a log(N)-wire efficiency claim.

## Identity, distinctness and entropy

The path factorization (a_1 a_2)...(a_(v-1) a_v) equals cycle c=(a_1 ... a_v). The ascending star factorization (a_1 a_2)(a_1 a_3)...(a_1 a_v) equals c^{-1}. Their product is identity. For v>=3 this is neither a word followed by its literal reverse nor adjacent doubled gates; only edge (a_1 a_2) repeats between the two initial halves, while the other 2m-2 edges are distinct. All per-position gates are marginally uniform by label symmetry. These observations do not imply security.

The injection is recoverable from the first m path edges: their successive intersections identify interior vertices, then the endpoints. This is injective for m>=2, hence base entropy is log_2((N)_v). Every fixed scrambling tape acts bijectively on words; mixing independent tapes cannot reduce this lower bound. The generated subgroup and support stay unchanged under each Hurwitz move: both old factors belong to the subgroup generated by the new pair and conversely. Therefore the support is exactly v labels before noise, for every scrambling tape and even with unlimited scrambling.

The semantic error bound on the schedule is min(1,4 floor(sqrt(lambda))/lambda^6); an inverse-polynomial upper bound is not negligible in the cryptographic sense.

## Scope and boundary handling

The finite C2 definition covers S3,L4 and S4,L4 (m=2), and S4,L6 (m=3). The attack schedule is much sparser, with N=lambda^6; tiny validation cases do not certify that asymptotic bound. m=0, m=1 and N=2 are outside C2, and separate game controls cover them. Odd length is rejected. k=0,k=1,k=L are valid channel variants, with k=L giving exactly iid gates in both worlds. The concrete attack must state when its support threshold is below the reference range; it cannot silently assert separation at k=L.
